# Online Retail Analytics Dashboard

An end-to-end retail analytics project that transforms raw transaction data into analytical datasets and an interactive Power BI dashboard.

The project covers data preprocessing, SQL-based data transformation, business analysis, and dashboard development using the Online Retail II dataset.

---

# Project Overview

This project analyzes online retail transaction data to understand:

- Sales performance and seasonal trends
- Customer purchasing behavior and value contribution
- Product performance across revenue and sales volume
- Business opportunities through data-driven insights

The analysis pipeline includes:

1. Data preprocessing using R
2. Data transformation using MySQL
3. Data visualization and dashboard development using Power BI
4. Business insights and recommendations

---

# Dataset

Dataset: **Online Retail II**

Source:
https://archive.ics.uci.edu/dataset/502/online+retail+ii

The dataset contains online retail transactions from a UK-based retailer between 2009 and 2011.

The original dataset includes:

- Invoice information
- Product details
- Customer identifiers
- Transaction dates
- Quantity and price information
- Customer country
